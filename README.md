# Cab Booking System 🚕

A modern, fast, and responsive **Cab Booking Web Application** built with **Next.js 14 (App Router)**, **React.js**, and **Tailwind CSS**.
Enabling users to book rides through an intuitive interface with optimized performance and seamless user experience across devices.

---

## 🚀 Live Demo

Check out the live deployment of the project here:  
🔗 **[Live Demo Link](https://github.io)** - **https://cab-booking-tcj.netlify.app/**

---

## 🛠️ Features

* Fast page loads and server-side rendering with **Next.js 14**
* Clean, modern, and fully responsive user interface styled with **Tailwind CSS**
* Interactive booking flow with pickup and drop-off location inputs
* Real-time fare estimation and cab type selection
* User-friendly interactive components built with **React.js**
---

## ⚒️ Tech Stack

* **Framework:** Next.js 14 (App Router)
* **Library:** React.js
* **Styling:** Tailwind CSS
* **Language:** JavaScript / TypeScript

## 🔑 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org) installed on your computer.
---
### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```

2. Move to the project directory:
   ```bash
   cd cab-booking-app
   ```

3. Install the required packages:
   ```bash
   npm install
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your web browser to see the app.
---
## 🔭 Project Structure

* `app/`: Next.js 14 App Router pages and layouts
* `components/`: Reusable React components (buttons, inputs, maps, cards)
* `public/`: Static assets and images
* `styles/`: Global CSS and Tailwind configurations
